# Layout Templates

Five layout types. Each slide picks the one matching its job. **Never use the same type on two
consecutive slides.** Below: when to use, the copy skeleton, and Canva/HTML placement notes.

---

## 1. `minimalist-text`
Headline + 1–2 line subhead. Maximum whitespace. The default for hooks and transitions.
```
HEADLINE: short, punchy (split: accent word in orange + rest in ink)
SUBHEAD:  one supporting line (sans, ink-soft)
```
Placement: headline in left 65%, vertically centered-high. Subhead below with gap. Page # bottom-left.

## 2. `stat-callout`
One oversized number, percentage, or pulled quote. Everything else recedes.
```
STAT:    the big figure or 4–8 word quote (display serif, huge; number can be orange)
CAPTION: one line of context (sans, small)
```
Placement: stat dominates center. Caption directly under, small. Use orange for the figure OR a
quotation accent, not both.

## 3. `bullet-list`
Short intro/kicker + **max 4** bullets. Never 5+. If you have more, split across two list slides or cut.
```
KICKER:  optional uppercase tracked label (orange)
HEADLINE: the list's promise (can use accent word)
BULLETS:
  • item one (≤6 words ideal)
  • item two
  • item three
  • item four   ← hard cap
```
Placement: round bullets, ink text, comfortable line gaps. Left-aligned.

## 4. `bold-statement`
One giant sentence fills the slide. No body text. Mic-drop / turning-point moments.
```
STATEMENT: one sentence, can break across lines, two-color split
           (e.g. first clause orange italic, second clause black roman)
```
Placement: text fills left 70%, large leading. No subhead. Page # bottom-left.

## 5. `story-beat`
Headline + body + a small graphic/sticker accent. Carries narrative moments.
```
HEADLINE: the beat (accent word optional)
BODY:     2–3 lines (≤40–50 words total slide)
GRAPHIC:  small orange sticker/icon/pixel accent, top-right-ish of the text block
```
Placement: headline upper-left, body under it, little graphic offset to the right for warmth.

## Rotation example (8-slide Story Arc)
| Slide | Job | Layout |
|------|-----|--------|
| 1 | Hook | minimalist-text |
| 2 | Conflict | story-beat |
| 3 | Stakes | bold-statement |
| 4 | Turning point | stat-callout |
| 5 | What changed | bullet-list |
| 6 | Resolution | story-beat |
| 7 | Lesson | bold-statement |
| 8 | CTA | minimalist-text |

No two adjacent rows repeat. Build the same kind of table mentally for every carousel before writing copy.

## CTA slide (always last)
One action only. Patterns that fit the style:
- Question headline (orange italic accent + ink) + "COMMENT \"GUIDE\" AND I'LL SEND IT" label.
- "Know someone who needs this? Share it." + {{HEADSHOT}} + "SHARE THIS POST" label.
- "Follow {{BRAND}} for more on [domain]." + small arrow.
Pick ONE. Never stack multiple asks.
