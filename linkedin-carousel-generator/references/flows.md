# Flow Types

Seven flows. Each maps a topic onto an ordered set of slide "jobs." Pick the flow that fits the
topic, then assign layout types so no two consecutive slides match (see `layouts.md`). All flows
must land between 6 and 10 slides, start with a ≤10-word hook, and end with one CTA.

Legend: each beat = one slide. Suggested layout in (parentheses) — swap if it would repeat the slide before.

---

## 1. Step-by-Step Guide (7–9 slides)
1. Hook — the outcome they want (minimalist-text)
2. Why it matters / cost of not knowing (story-beat)
3–N. One step per slide (alternate bullet-list / story-beat / bold-statement)
N+1. Quick recap (bullet-list, max 4)
Last. CTA — "comment KEYWORD for the full guide" (minimalist-text)

## 2. Story Arc (7–9 slides)
1. Hook — drop into the moment (minimalist-text)
2. Conflict — what went wrong (story-beat)
3. Stakes — why it mattered (bold-statement)
4. Turning point (stat-callout or story-beat)
5. Resolution — what you did (bullet-list or story-beat)
6. Lesson — the transferable insight (bold-statement)
7. CTA (minimalist-text)

## 3. List Breakdown (6–10 slides)
1. Hook — "N things that…" (minimalist-text)
2. Promise / why this list (story-beat)
3–N. One list item per slide, or grouped 4-bullet slides (alternate bullet-list / bold-statement)
N+1. The punchline item or summary (stat-callout)
Last. CTA — save / follow (minimalist-text)

## 4. Myth vs Reality (6–8 slides)
1. Hook — name the belief (minimalist-text)
2. "The myth:" stated plainly (bold-statement)
3. Why it's wrong (story-beat)
4. "The reality:" (bold-statement)
5. Proof / example / stat (stat-callout)
6. So what — what to do instead (bullet-list)
Last. CTA (minimalist-text)

## 5. Day-in-the-Life (7–9 slides)
1. Hook — "A day as a [role]" (minimalist-text)
2–N. Timeline beats (morning → deep work → blockers → win), one per slide
     (alternate story-beat / stat-callout / bold-statement)
N+1. The honest insight behind the routine (bold-statement)
Last. CTA — "what does yours look like?" (minimalist-text)

## 6. Before/After (6–8 slides)
1. Hook — the transformation in one line (minimalist-text)
2. Before — the painful state (story-beat)
3. The shift — what changed (bold-statement)
4. After — the new state (story-beat or stat-callout)
5. How (the few moves that mattered) (bullet-list, max 4)
6. Lesson (bold-statement)
Last. CTA (minimalist-text)

## 7. Stat-Driven (6–9 slides)
1. Hook — a surprising stat as a question (minimalist-text)
2. The headline stat, oversized (stat-callout)
3. Context — what it means (story-beat)
4–N. Supporting stats, one per slide (alternate stat-callout / bold-statement)
N+1. The takeaway (bold-statement)
Last. CTA (minimalist-text)

---

## Choosing a flow from a topic
- Personal experience / "I once…" → Story Arc or Before/After
- "How to" / process → Step-by-Step Guide
- "X myths" / pushing back on common advice → Myth vs Reality
- "N reasons / lessons / tools" → List Breakdown
- Data, benchmarks, survey numbers → Stat-Driven
- Showing the texture of your work → Day-in-the-Life

If unsure, default to Story Arc for personal/career topics and Step-by-Step for tactical/AI topics.
State the chosen flow in one line before the slides.
